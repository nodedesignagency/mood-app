# The app is the native iOS one

`apple/` is the app: SwiftUI, iOS 26+. Work there. Its own README covers how
to open it, generate the Xcode project, and run it from the terminal.

The Expo / React Native project at the repo root — `App.tsx`, `src/`,
`package.json` — came first and is kept for reference only. It is not being
developed, not shipped, and not kept in step with `apple/`. Leave it alone
unless it is asked for by name.
